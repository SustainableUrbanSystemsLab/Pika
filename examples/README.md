# Current examples

| Folder | Example | Use |
|---|---|---|
| `geometry/` | `Start_Here.3dm` + `Geometry_Workflow.gh` | Main-plugin selector → geometry → candidate layout; six-panel baseline |
| `solar/` | `Solar_Workflow.gh` | Experimental Conditions → Exposure → Map/Electricity; synthetic weather |

Use millimeters for the embedded example geometry. Distance inputs on the custom components are meters.

The separately delivered advisor package is a standalone review build with different component IDs; use the example shipped inside that package with that review plugin. The main examples here use the original development component IDs.

Older tutorial/legacy definitions were removed from the working repository after making an external backup; the current build does not register obsolete component types.
